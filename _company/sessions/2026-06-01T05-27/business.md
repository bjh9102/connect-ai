# 💼 현빈 — MOMOBOOK (모모북)
프로젝트 개요

모모북(MOMOBOOK)은 부모가 입력한 정보를 기반으로 AI가 아이를 주인공으로 한 맞춤형 그림 동화책을 생성하는 서비스이다.

부모는 아이의 이름, 나이, 좋아하는 것, 교육하고 싶은 주제를 입력하고, AI는 이를 기반으로 동화 스토리와 삽화를 생성하여 전자책(E-Book) 형태로 제공한다.

비전

"우리 아이가 주인공이 되는 첫 번째 동화책"

기존 동화책은 모든 아이가 같은 이야기를 읽는다.

모모북은 아이 개개인의 특성을 반영하여 세상에 하나뿐인 동화를 만들어 준다.

문제 정의

부모들은 다음과 같은 고민을 가지고 있다.

아이에게 좋은 가치관을 알려주고 싶다.
매일 같은 동화를 읽어주기 지겹다.
아이가 자신의 이야기에 더 몰입한다.
교육적인 내용을 자연스럽게 전달하고 싶다.

모모북은 AI를 활용하여 이러한 문제를 해결한다.

모모북은 단순한 AI 동화 생성기가 아니다.

모모북은

"우리 아이가 주인공이 되는 성장 스토리 플랫폼"

을 지향한다.

장기적으로는

부모 데이터
아이 프로필 데이터
동화 구조 데이터
사용자 피드백 데이터

를 기반으로 동화 전문 AI 모델 구축을 목표로 한다.

현재 목표

완벽한 서비스를 만드는 것이 목표가 아니다.

목표는

"부모 10명이 실제로 사용해보는 MVP를 출시하는 것"

이다.

최대한 빠르게 만들고,
최대한 빨리 검증한다.

💼 현빈: 사장님, PayPal Client ID 또는 Secret 이 비어있어 매출을 가져올 수 없어요.

📋 **해결 단계**:
1. `Cmd+Shift+P` → `Connect AI: 외부 연결`
2. 💰 PayPal 카드 → Client ID + Secret 입력
3. 저장 → 즉시 매출 분석 가능

📊 평가: 대기 — PayPal 자격증명 입력 후 재시도.
📝 다음 단계: 사장님이 PayPal Developer Dashboard 에서 Client ID/Secret 복사 → 외부 연결 패널 입력.
